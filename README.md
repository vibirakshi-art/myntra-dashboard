# Myntra Product Sales & Pricing Analysis Dashboard Using Excel

## Project Overview
This project analyzes Myntra product data and creates an interactive dashboard using Microsoft Excel. The goal is to understand product pricing, discounts, ratings, and brand performance through data visualization.

## Features
- Total Price Analysis
- Total MRP Analysis
- Discount Percentage Analysis
- Product Ratings Analysis
- Number of Ratings Analysis
- Brand-wise Product Analysis
- Interactive Filters using Slicers

## Tools Used
- Python (Web Scraping)
- Pandas (Data Cleaning)
- Microsoft Excel (Dashboard Creation)
- CSV File Storage

## Dataset Information
The dataset contains:
- brand_name
- price
- MRP
- discount_percent
- ratings
- no_of_ratings
- pants_description

## Process
1. Collected product data from Myntra using web scraping
2. Cleaned the dataset using Python Pandas
3. Stored cleaned data in CSV format
4. Imported dataset into Excel
5. Created Pivot Tables
6. Built Pivot Charts
7. Added Slicers for filtering
8. Designed final dashboard
